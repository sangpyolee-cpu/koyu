# 실제 포스팅 과정: 글감 찾기 → 제목 → 초안 (애드포스트 월 100만원 달성기 EP9)

## 핵심 주장

글 하나를 쓰는 실제 과정을 화면 녹화로 보여줌. 글감 찾기 → 제목 뽑기 → 초안 작성을 챗봇과 같이 돌리면 "오늘 뭐 쓰지?" 하며 흘려보내는 시간이 줄어든다는 내용.

## 작업 순서 (화면·자막 기준)

1. **글쓰기 화면을 모바일 모드로 전환**: PC에서 네이버 블로그 글쓰기에 들어간 뒤 오른쪽 위에서 모바일 화면으로 바꿔 놓고 작성.
2. **글감 찾기 — 블로그 통계의 크리에이터 어드바이저**: 내 블로그 → 통계 → 왼쪽 메뉴를 내려 "어드바이저" → 상단 "트렌드" 탭 → "검색 유입 트렌드". 주제별 인기 유입 검색어가 맛집·국내여행·패션미용·일상생각 등으로 나뉘어 나옴.
3. **내 블로그 주제에 맞는 키워드 고르기**: 본인은 일상·생각 블로그라 그 목록에서 쓸 수 있는 것을 고름. 예시로 "코스트코 회원권"을 선택.
4. **네이버 자동완성으로 좁히기**: 네이버에 "코스트코 회원권"을 치면 자동완성에 "코스트코 회원권 없이"가 뜸. 자동완성은 사람들이 실제로 검색하는 말이므로, 회원권이 없어도 이용할 수 있는지 궁금해한다는 뜻으로 해석하고 이를 메인 키워드로 결정.
5. **블로그 챗봇(ChatGPT 맞춤 챗봇)에 키워드 입력**: 챗봇이 먼저 무엇이 궁금한지 되묻고 입력 양식(메인 키워드, 서브 키워드, 방문한 지점, 체험 날짜, 누구와 갔는지, 이용 방법, 좋았던 점, 아쉬웠던 점, 독자가 알고 싶을 정보, 넣고 싶은 개인 경험, 원하는 톤)을 제시. "회원권 없이 코스트코 이용하는 방법"으로 다시 요청하면 검색 후 1,500자 안팎의 SEO 후기글을 작성.
6. **챗봇 결과물**: 블로그 제목 추천 5개, 추천 썸네일 문구 5개, 소제목이 붙은 본문 약 1,500자(예: "코스트코 회원권 없이 쇼핑할 수 있을까?", "상품권 이용 전 알아둘 점", "이런 분들께 추천해요").
7. **제목 붙여넣기**: 최종 제목 "코스트코 회원권 없이 쇼핑 가능할까? 비회원 이용 방법 총정리"를 글쓰기 화면에 입력. 제목 위에 유사율 표시(예: 65.5%)가 뜨는 것으로 보아 제목 유사도 확인 확장프로그램을 함께 사용.

## 캡션에서 강조한 것

- 잘 쓰는 것보다 계속 쓰는 게 먼저.
- 하루 한 편이 부담이면 도구를 쓰면 된다.
- 루틴이 된 사람만 숫자가 움직인다. 글 발행이 양치나 아침 커피처럼 그냥 하는 일이 되어야 쌓인다.
- 수익 연결 경로: 애드포스트, 쇼핑커넥트, 여행커넥트.

## 확인하지 못한 것

- 음성은 받아 적지 못했고, 화면을 2초 간격으로 읽어 자막 일부는 빠졌을 수 있습니다.
- 챗봇 자체는 댓글에 "챗봇"을 남기면 보내주는 방식이라 프롬프트(지시문)는 보지 못했습니다. 위 입력 양식은 화면에 비친 것을 읽은 것입니다.
