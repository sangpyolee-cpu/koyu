# PROJECT_OVERVIEW — Naver Travel & Food Blog Automation

- 문서 상태: 설계 초안 (승인 대기)
- 작성일: 2026-11-16
- 범위: 1단계(자료 분석과 설계). 글 작성, 발행, API 연결, 로그인·브라우저 자동화는 포함하지 않는다.

## 1. 이 프로젝트가 무엇인가

네이버 블로그에서 국내·해외 여행과 맛집을 다루는 개인 블로그를 처음부터 만들고, 운영 업무를 단계적으로 자동화하는 프로젝트다. 자동화의 대상은 "글을 대신 써서 올리는 것"이 아니라 글감 찾기, 구성 잡기, 초안 정리, 점검, 통계 해석처럼 반복되는 준비 작업이다. 방문과 경험, 사실 확인, 발행 결정은 사람이 한다.

## 2. 확정 사항

| 항목 | 내용 |
|---|---|
| 플랫폼 | 네이버 블로그 |
| 분야 | 국내 및 해외 여행 / 맛집 |
| 콘텐츠 방식 | 정보성 콘텐츠 + 실제 방문 후기 |
| 개발 환경 | Claude Code |
| 운영 목표 | 지속 가능한 콘텐츠 생산, 블로그 수익화 |
| 최종 목표 | 블로그 운영 업무의 단계적 자동화 |

주제와 플랫폼은 확정이므로 이 프로젝트의 어떤 문서도 다른 주제나 플랫폼을 제안하지 않는다.

## 3. 운영 원칙

1. **경험이 먼저다.** 방문하지 않은 장소를 방문한 것처럼 쓰지 않는다. 방문 기록이 없는 장소는 정보성 글로만 다루고, 그 사실을 글에 밝힌다.
2. **확인되지 않은 사실은 쓰지 않는다.** 영업시간, 가격, 메뉴는 직접 확인한 근거(사진, 영수증, 공식 채널)와 확인일이 있을 때만 쓴다. 근거가 없으면 비워 두고 공식 채널 확인을 안내한다.
3. **대량 자동 발행을 목표로 하지 않는다.** 발행 속도보다 글 하나의 품질과 지속성을 우선한다.
4. **사람의 승인이 과정 안에 있다.** 키워드 선정, 초안, 사실 확인, 발행 각 단계에 승인 지점을 둔다.
5. **자료에 근거한다.** 설계 판단은 학습 자료와 공식 자료에 근거하고, 근거가 없는 부분은 "미확인"으로 표시한다.
6. **초보자 기준으로 설명한다.** 구현 전에 구조와 이유를 먼저 설명하고, 한 번에 한 단계씩 만든다.

## 4. 시스템 구성 (개요)

```
[사람] 방문·촬영·메모 ──┐
                        ▼
① 글감 발굴 → ② 기획(제목·목차) → ③ 초안 → ④ 점검(SEO·사실·표시) → ⑤ 발행 → ⑥ 통계 회고
   승인 G1        승인 G2            승인 G3      승인 G4               사람이 직접     다음 글감으로
```

- ①②③④⑥은 Claude Code가 보조한다. ⑤ 발행은 사람이 네이버 편집기에서 직접 한다.
- 지역이 모든 데이터의 연결 기준이다. 한 번의 여행에서 여행 후기, 맛집 후기, 정보성 글, 지역 모음글이 함께 나오고 서로 연결된다.
- 상세 구조는 `AUTOMATION_ARCHITECTURE.md`에 있다.

- N1~N8은 본문 텍스트를 읽었고 본문 속 그림(도표)은 읽지 못했다.
- 애드포스트 미디어 등록의 구체적 수치 기준(운영 기간, 글 수, 방문자 수)은 A1에 없다. 인터넷에 도는 "개설 90일" 등은 공식 원문에서 확인하지 못했다.
- 네이버 블로그의 'AI 활용' 표시 기능은 언론 보도로만 확인했고 네이버 공지 원문은 찾지 못했다. 블로그에서 의무인지 자율인지는 보도마다 다르다.
- 쇼핑 커넥트, 여행 커넥트 등 제휴 프로그램의 현재 참여 조건과 수수료는 공식 원문을 확인하지 못했다.
- 네이버 블로그 글쓰기 Open API의 현재 제공 여부는 확인하지 않았다(1단계 범위 밖).
