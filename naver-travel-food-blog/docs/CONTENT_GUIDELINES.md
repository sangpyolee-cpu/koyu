# CONTENT_GUIDELINES — 콘텐츠 작성 기준

- 문서 상태: 설계 초안 (승인 대기)
- 근거 기호는 `PROJECT_OVERVIEW.md` 6절 참고
- 이 문서는 사람과 AI 모두에게 적용된다. 자동화 도구는 이 문서의 기준을 검수 항목으로 사용한다.

## 1. 절대 원칙

1. **방문하지 않은 곳을 방문한 것처럼 쓰지 않는다.** 후기는 방문 기록 카드가 있는 장소만 쓴다.
2. **확인되지 않은 영업시간, 가격, 메뉴를 만들어내지 않는다.** 근거와 확인일이 없으면 쓰지 않는다.
3. **맛, 분위기, 친절도 같은 평가는 사용자의 메모에서만 나온다.** AI가 추측해 채우지 않는다.
4. **경제적 대가를 받았으면 제목이나 글 첫 부분에 밝힌다.** (F1)
5. **남의 글과 사진을 가져오지 않는다.** 인용하면 출처와 원문 링크를 넣는다. (N5)

## 2. 방문 기록 카드

후기를 쓰기 위한 최소 근거다. 방문할 때 또는 직후에 사람이 작성한다. 비어 있는 칸은 글에서도 비워 둔다.

| 항목 | 내용 | 비고 |
|---|---|---|
| 장소 | 정확한 상호·명칭, 지역 | 간판 또는 공식 표기 기준 |
| 방문일·시간대 | 날짜, 요일, 대략의 시간 | 필수 |
| 동행·목적 | 혼자, 커플, 가족, 아이 동반 등 | 독자 상황 설명에 쓴다 (N6) |
| 결제 | 내돈내산 / 협찬 / 원고료 | 필수, 표시 문구 결정 |
| 주문·이용 내역 | 실제 주문한 메뉴, 이용한 시설 | 먹지 않은 메뉴는 평가하지 않는다 |
| 가격 | 영수증 또는 메뉴판 사진 기준 금액 | 근거 사진 필수 |
| 영업시간·휴무 | 현장 안내문 사진 또는 공식 채널 | 근거와 확인일 필수 |
| 가는 방법 | 실제 이용한 교통, 주차, 걸린 시간 | 직접 겪은 것만 |
| 대기·예약 | 실제 대기 시간, 예약 방법 | |
| 좋았던 점 | 사용자 메모 | |
| 아쉬웠던 점 | 사용자 메모 | N6: 시행착오와 아쉬움이 신뢰를 높인다 |
| 팁 | 가 본 사람만 아는 것 | N6 셀프 체크 2번 |
| 비교·대안 | 함께 고민한 곳, 고른 이유 | N6 셀프 체크 3번 |
| 사진 목록 | 직접 찍은 사진과 각 사진의 내용 | 타인 얼굴, 차량 번호 등 확인 |

R3의 챗봇이 글을 쓰기 전에 묻는 항목(방문 지점, 체험 날짜, 누구와, 좋았던 점, 아쉬웠던 점, 넣고 싶은 개인 경험)과 같은 방향이다.

## 3. 사실 정보 표기 규칙

| 정보 | 쓸 수 있는 조건 | 표기 방법 |
|---|---|---|
| 가격·메뉴 | 영수증, 메뉴판 사진이 있을 때 | "방문일 기준"임을 밝힌다 |
| 영업시간·휴무일 | 현장 안내문 또는 공식 채널을 확인했을 때 | 확인일을 적고 "방문 전 공식 채널 확인"을 안내한다 |
| 주소·위치 | 지도 서비스의 장소 정보로 확인했을 때 | 지도 첨부를 기본으로 한다 |
| 교통·소요 시간 | 직접 이용했을 때 | 직접 걸린 시간임을 밝힌다 |
| 입장료·예약 조건 | 공식 사이트를 확인했을 때 | 출처 링크와 확인일을 적는다 |
| 해외 비자·환율·안전 정보 | 공식 기관 자료를 확인했을 때 | 출처 링크와 확인일을 적는다. 바뀌기 쉬운 정보는 수치를 적기보다 공식 링크로 안내한다 |

근거가 없으면 해당 문장을 쓰지 않는다. "보통 ~라고 한다", "~인 것 같다"로 메우지 않는다.

## 4. 유형별 구성

분량은 고정하지 않는다. 자료마다 기준이 다르기 때문이다(R1은 2,000자 안팎, R3의 챗봇은 1,500자 안팎, R5의 시연에서 한 키워드의 상위 10개 글 평균은 2,019자·사진 9장). 목표 키워드의 상위 글을 확인해 참고하되, 쓸 내용이 없는데 분량을 채우지 않는다.

### A. 여행 후기

1. 첫 문단: 누구와 언제 어디를 다녀왔고, 이 글에서 무엇을 알 수 있는지 (R1: 답부터 시작)
2. 전체 일정 요약 (표 또는 목록)
3. 시간 순서대로 장소별 경험: 이동, 소요 시간, 좋았던 점, 아쉬웠던 점 (N6: 시간과 절차의 흐름)
4. 다녀온 사람만 아는 팁과 주의 사항
5. 비용 정리 (근거가 있는 항목만)
6. 이런 사람에게 맞는다 / 맞지 않는다 (N6: 상황별 선택지)
7. 같은 지역의 맛집 후기, 정보성 글 안내 (내부 링크 2개 이상)

### B. 맛집 후기

1. 첫 문단: 어떤 상황에서 갔고 한 줄 결론은 무엇인지
2. 기본 정보: 위치, 가는 방법, 주차, 대기·예약 (확인된 것만)
3. 주문한 메뉴와 가격 (방문일 기준)
4. 메뉴별 솔직한 평가: 좋았던 점과 아쉬웠던 점
5. 공간, 좌석, 동행 유형별 적합성
6. 팁: 추천 시간대, 주문 요령 등 직접 겪은 것
7. 같은 지역의 여행 후기, 다른 맛집 후기 안내

### C. 정보성 글

1. 첫 문단: 검색한 사람이 찾는 답을 먼저 쓴다 (R1)
2. 핵심 정보를 표·목록으로 구조화 (N5: 읽기 쉬운 구조)
3. 항목별 설명과 출처 링크·확인일
4. 직접 겪은 경험이 있으면 구분해서 덧붙인다. 방문 경험 없이 쓰는 글이면 그 사실을 밝힌다
5. 관련 후기 글 안내

### D. 지역 모음글

1. 이 지역을 언제, 몇 번, 어떻게 다녀왔는지
2. 추천 동선 요약
3. 여행 후기, 맛집 후기, 정보성 글로의 안내 (각 글의 한 줄 요약과 링크)
4. 새 글이 생기면 갱신한다 (N5: 최신성 유지)

## 5. 문장과 형식

- 제목, 소제목, 문단 나누기를 적극적으로 쓴다 (N5).
- 문장은 짧게 쓰고, 소제목마다 핵심을 한 줄로 정리한다 (R1).
- 광고처럼 들리는 말투와 같은 말의 반복을 뺀다 (R1, N5).
- 누구나 쓸 수 있는 일반론("분위기가 좋고 가격도 합리적")을 피하고, 구체적인 상황과 수치를 쓴다 (N6).

## 6. 사진과 이미지

- 직접 찍은 사진만 쓴다. 본문 내용과 직접 관련된 사진을 그 내용 옆에 둔다 (N6).
- 사진으로 전달하는 핵심 정보(메뉴판의 가격, 안내문의 시간)는 본문 텍스트로도 적는다 (N5, N6).
- 본문과 무관한 사진을 분량을 위해 넣지 않는다 (N5).
- 대표 썸네일 문구는 10자 이내를 기본으로 한다 (R1).
- AI로 만든 이미지를 실제 장소나 음식 사진처럼 쓰지 않는다.
- 타인의 얼굴, 차량 번호 등 개인을 알아볼 수 있는 정보는 가린다. A1은 타인의 개인정보를 동의 없이 게시한 게시물을 부적합 콘텐츠로 든다.

## 7. 경제적 대가 표시

| 상황 | 표시 |
|---|---|
| 직접 결제 | 직접 구매·결제했음을 본문 앞부분에 밝힌다 (N5) |
| 협찬, 무료 제공, 원고료 | 제목 또는 글 첫 부분에, 본문과 구분되게 표시한다 (F1) |
| 제휴 링크 수수료 | 수수료를 받을 수 있음을 글 첫 부분에 표시한다 (F1) |

- 댓글이나 '더보기' 뒤에 숨기는 방식은 적절한 표시가 아닐 수 있다 (F1).
- 대가를 받았더라도 아쉬운 점을 빼지 않는다. N5는 홍보성 문구만 가득한 글이 불리하게 작용할 수 있다고 밝힌다.
- 구체적 문구는 수익화를 시작하기 전에 공정거래위원회 안내서(F2)의 블로그 예시를 보고 확정한다.

## 8. 발행 전 검수표

모든 항목이 "예"일 때만 발행한다. 1~4번은 사람만 판단할 수 있다.

| 번호 | 항목 | 근거 |
|---|---|---|
| 1 | 방문 기록 카드가 있고, 글의 경험 서술이 카드와 일치하는가 | 절대 원칙 |
| 2 | 가격, 메뉴, 영업시간에 근거와 확인일이 있는가 | 절대 원칙 |
| 3 | AI가 덧붙인 경험·평가·사실이 없는가 | 절대 원칙 |
| 4 | 대가 여부가 제목 또는 첫 부분에 표시되었는가 | F1, N5 |
| 5 | 누가 어떤 상황에서 찾는 글인지 분명한가 | N6-1 |
| 6 | 경험이 시간·절차 순서로 구체적으로 쓰였고 팁·주의 사항이 있는가 | N6-2 |
| 7 | 비교한 대안이나 상황별 추천이 있는가 | N6-3 |
| 8 | 결과, 아쉬운 점, 시행착오가 담겼는가 | N6-4 |
| 9 | 사진이 본문과 맞고, 핵심 정보가 텍스트로도 있는가 | N6-5 |
| 10 | 첫 문단이 검색한 사람의 질문에 답하는가 | R1 |
| 11 | 키워드가 제목·첫 문단·소제목에 자연스럽게 들어갔고 억지 반복이 없는가 | R1, N5 |
| 12 | 태그가 3~5개이고 본문과 연관되는가 | R4 |
| 13 | 같은 지역의 내 글로 가는 링크가 있는가 | R1 |
| 14 | 사용자가 처음부터 끝까지 읽고 직접 고쳤는가 | N5 |

## 9. 아직 결정되지 않은 사항

- 글의 말투(존댓말 수준, 1인칭 표현)와 필명
- 평가를 점수로 표기할지, 문장으로만 쓸지
- 아쉬운 경험만 있었던 장소를 글로 쓸지 여부와 기준
- 사진 보정·워터마크 기준
