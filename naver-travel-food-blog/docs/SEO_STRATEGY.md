# SEO_STRATEGY — 네이버 검색 전략

- 문서 상태: 설계 초안 (승인 대기)
- 근거 기호는 `PROJECT_OVERVIEW.md` 6절 참고

## 1. 네이버 검색이 공식적으로 밝힌 평가 방식

| 구분 | 내용 | 출처 |
|---|---|---|
| C-Rank | 문서의 출처인 블로그의 신뢰도를 평가한다. 주제별 관심사의 집중도(Context), 생산되는 정보의 품질(Content), 콘텐츠의 소비·생산 연쇄 반응(Chain)으로 얼마나 믿을 수 있고 인기 있는 블로그인지(Creator)를 계산한다. 결과는 랭킹에 "일부" 반영된다 | N1 |
| D.I.A. | 문서 자체를 평가한다. 주제 적합도, 경험 정보, 정보의 충실성, 문서의 의도, 상대적인 어뷰징 척도, 독창성, 적시성 등이 반영된다 | N2 |
| 두 모델의 관계 | 서로 보완한다. 항상 상위 노출을 고정적으로 보장하는 출처 개념은 없다 | N2 |
| 현재 적용 | UGC 검색에 C-Rank, D.I.A.+, 유사문서 판독 시스템이 적용되어 있다. LLM으로 문서 평가를 고도화해 자동 생성된 저품질 콘텐츠와 경험에 기반하지 않은 광고성 도배글을 더 정교하게 판별한다 | N3 |
| 유사문서 | 원본과 복사된 글을 판별하는 시스템이 더 빠르고 정확해졌다 | N3 |
| 통합 랭킹 | 문서 유형과 관계없이 공신력·공식성·전문성이 높은 출처를 상위에 보여주는 모델을 테스트했다 | N4 |
| AI 브리핑 | 기존 검색 결과에 잘 노출되는 양질의 글이 AI 브리핑에 인용될 가능성이 높다. 꾸준히 양질의 글을 써온 채널이 더 자주 인용될 수 있다 | N5 |
| 경험 UGC 블록 | 경험·후기가 궁금한 검색에서 글을 관심사별 소제목으로 묶어 보여주고, 본문 중 관련 부분을 발췌한다 | N8 |

네이버는 N1에서 "검색 결과 1등으로 올릴 수 있는 꼼수"를 기대하지 말라고 밝힌다. 이 문서의 전략도 순위 조작 기법이 아니라 위 평가 방식에 맞는 글을 쓰는 방법이다.

## 2. 전략 요약

1. **출처 신뢰도:** 여행·맛집 주제에 집중해 꾸준히 쓴다 (N1, N5).
2. **문서 품질:** 직접 경험, 충실한 정보, 독창성, 적시성을 갖춘다 (N2, N5, N6).
3. **검색 의도 일치:** 사람들이 실제로 검색하는 말로 글감을 정하고, 첫 문단에서 답한다 (R1, R3).
4. **구조:** 소제목, 표, 목록으로 발췌되기 쉽게 쓴다 (N5, N8).
5. **지역 연결:** 같은 지역의 글을 서로 연결한다 (`BLOG_STRATEGY.md`).

## 3. 키워드 발굴 절차

학습 자료에서 확인된 방법을 순서대로 묶었다. 1~3단계는 네이버가 제공하는 화면만 사용한다.

| 단계 | 방법 | 출처 |
|---|---|---|
| 1. 후보 수집 | 내 블로그 통계의 어드바이저 → 트렌드 → 검색 유입 트렌드에서 "맛집", "국내여행" 등 내 주제의 인기 유입 검색어를 본다 | R3 |
| 2. 표현 좁히기 | 후보를 네이버에 입력해 자동완성에 뜨는 표현을 확인한다. 자동완성은 사람들이 실제로 검색하는 말이다 | R3 |
| 3. 검색 결과 확인 | 그 키워드로 검색해 어떤 유형의 글과 블록이 나오는지 본다. 경험 UGC 블록의 소제목은 지금 사람들이 궁금해하는 관심사다 | N8 |
| 4. 수요 확인 (선택) | 확장프로그램으로 검색량, 월별 추이, 성별·연령 비율을 본다 | R2, R5 |
| 5. 상위 글 확인 (선택) | 상위 글의 글자 수, 사진 수, 키워드 수 평균을 참고한다 | R5 |
| 6. 선정 | 내가 방문 기록을 가진 장소·지역과 맞는 키워드만 고른다 | 운영 원칙 |

- 신규 블로그는 어드바이저 화면이 바로 제공되는지, 메뉴 위치가 R3와 같은지 세팅 단계에서 확인한다.
- 4~5단계의 확장프로그램은 제3자 도구다. 수치는 공식 통계가 아니라 참고값이다. 설치 여부는 5절의 유의 사항을 보고 사용자가 정한다.
- **6단계가 핵심이다.** 검색량이 많아도 다녀오지 않은 곳은 후기 글감이 될 수 없다. 키워드에서 장소를 고르는 것이 아니라, 다녀온 장소에서 키워드를 찾는다.

### 여행·맛집 키워드의 형태

R1의 Keyword Researcher 프롬프트는 키워드를 검색 이유별로 나누고, 경쟁이 덜한 긴 키워드를 표시하도록 한다. 이를 여행·맛집에 맞추면 다음과 같다.

| 검색 이유 | 형태 (지역·대상은 자리 표시) | 맞는 글 유형 |
|---|---|---|
| 장소 찾기 | [지역] 맛집, [지역] 가볼만한곳 | 지역 모음글 |
| 특정 장소 확인 | [상호] 후기, [상호] 웨이팅, [상호] 주차 | 맛집 후기 |
| 상황별 선택 | [지역] 아이와, [지역] 혼밥, [지역] 데이트 | 맛집·여행 후기 |
| 일정 짜기 | [지역] 1박2일 코스, [도시] 3박4일 일정 | 여행 후기 |
| 방법·준비 | [도시] 공항에서 시내, [지역] 예약 방법 | 정보성 글 |
| 비교 | [A] vs [B], [지역] 숙소 위치 비교 | 정보성 글 |

신규 블로그는 출처 신뢰도가 쌓이지 않았으므로 "지역 + 상황", "상호 + 궁금한 점"처럼 구체적인 긴 키워드부터 시작한다.

## 4. 글 단위 최적화 기준

| 요소 | 기준 | 출처 |
|---|---|---|
| 제목 | 메인 키워드를 앞쪽에 둔다. 숫자·기간·결과 중 하나를 넣는다. 본문 내용과 다른 과장을 하지 않는다 | R1 |
| 제목 중복 | 다른 글과 지나치게 비슷한 제목을 피한다 | R2, R3 (유사도 표시 도구) |
| 첫 문단 | 검색한 사람이 찾는 답을 먼저 쓴다 | R1 |
| 소제목 | 독자의 질문 단위로 나눈다. 키워드는 자연스러운 곳에만 넣는다 | R1, N5, N8 |
| 본문 | 경험 정보와 구체적 수치·절차를 담는다 | N2, N6 |
| 키워드 반복 | 억지로 반복하지 않는다. 반복 횟수를 목표로 삼지 않는다 | N5, A1 |
| 이미지 | 본문과 맞는 직접 촬영 사진을 쓰고, 핵심 정보는 텍스트로도 적는다 | N5, N6 |
| 표·목록 | 가격, 일정, 비교는 표로 정리한다 | N6 |
| 내부 링크 | 같은 지역의 내 글 2개 이상 | R1 |
| 외부 링크 | 공식 출처 링크는 넣되, 홍보 목적의 외부 링크를 과도하게 넣지 않는다 | N5 |
| 태그 | 본문과 연관된 3~5개 | R4 |
| 최신성 | 방문일·확인일을 적고, 정보가 바뀌면 수정한다 | N5 |

### 분량과 사진 수

정해진 정답이 없다. 목표 키워드의 상위 글을 참고해 독자가 필요한 정보를 다 담았는지를 기준으로 한다. 분량을 채우기 위한 문장과 사진은 넣지 않는다.

## 5. 도구 사용 기준

| 도구 | 용도 | 출처 | 유의 사항 |
|---|---|---|---|
| 네이버 블로그 통계·어드바이저 | 글감 발굴, 주간 회고 | R3 | 네이버 제공 화면 |
| 네이버 자동완성·검색 결과 | 검색 표현과 의도 확인 | R3, N8 | 네이버 제공 화면 |
| 이커머스 AI 솔루션 | 검색량, 월별 추이, 성별·연령 | R2, R5 | 제3자 확장프로그램 |
| 데이터랩툴즈 헬퍼 | 글자 수, 키워드 사용 횟수, 제목 유사도 | R2, R5 | 제3자 확장프로그램 |
| 리뷰언즈 엔서포터 | 상위 글 평균 지표 | R5 | 제3자 확장프로그램 |
| 네이버 블로그 파워 단축키 | 서식 단축키 | R2 | 제3자 확장프로그램 |

제3자 확장프로그램 유의 사항:

- 네이버가 만든 도구가 아니다. 표시되는 수치의 산출 방식은 확인되지 않았다.
- 브라우저 확장프로그램은 방문하는 페이지의 내용을 읽을 수 있다. 설치 전에 크롬 웹스토어의 권한 안내와 제공자를 확인하고, 필요한 것만 설치한다.
- 이 도구들 없이도 3절의 1~3단계와 6단계만으로 운영을 시작할 수 있다.

## 6. 하지 않는 것

- 본문과 무관한 키워드·태그 삽입, 배경색과 같은 글자색으로 키워드를 숨기는 행위 (N5, A1)
- 다른 글을 베끼거나 재조합한 글 (N3, N5)
- 방문자 수, 공감, 댓글, 이웃을 인위적으로 늘리는 프로그램이나 품앗이. A1은 비정상적으로 트래픽을 유도하는 경우를 등록 제한 사유로 든다
- "저품질", "최적화 블로그" 같은 비공식 개념에 맞춘 운영. N1은 이런 개념에 매몰되어 불필요한 일에 노력을 쓰는 것이 무의미하다고 밝힌다

## 7. 측정과 회고

- 주 1회 통계를 확인한다: 조회수, 유입 키워드, 인기 글 (R1의 Growth Analyst).
- 잘된 글과 안 된 글의 차이를 정리해 다음 글감에 반영한다 (R1).
- 유입 키워드 중 아직 글이 없는 표현은 새 글감 후보로 넣는다.
- 통계 수집은 처음에는 사용자가 화면의 수치를 복사해 붙여 넣는 방식으로 한다. 자동 수집은 1단계 범위 밖이다.

## 8. 미확인·미결정 사항

- 플레이스(지도) 리뷰와 블로그 글의 연계 방식, 블로그 글에 장소 정보를 첨부했을 때의 효과는 공식 자료에서 확인하지 못했다.
- 'AI 활용' 표시 기능을 블로그 글에 적용해야 하는 범위는 공식 공지를 확인하지 못했다. AI를 보조 도구로 쓰는 이 프로젝트의 방식에 표시가 필요한지 세팅 단계에서 편집기 화면과 공지를 확인한다.
- 제3자 확장프로그램 설치 여부 (사용자 결정)
