요청: $ARGUMENTS

상세페이지에 실제로 적힌 내용만으로 아래 [제품 스펙] 양식을 채운다. 추측으로 빈칸을 메우지 않는다.

## 1. 수집
- **URL이면** `curl -sS`로 HTML을 받는다(작업 파일은 스크래치 폴더, 저장소에 커밋하지 않음).
  - 소비자가·판매가·쿠폰 적용가: 페이지 텍스트의 `소비자가`, `판매가`, `쿠폰 적용가` 줄.
  - **사이즈별 가격**: 카페24 `option_stock_data`에서 옵션 조합별 판매가를 뽑는다.
    ```python
    import re, json
    s = open('page.html', encoding='utf-8', errors='ignore').read()
    raw = re.search(r"var option_stock_data = '(.*?)';", s).group(1)
    d = json.loads(raw.encode().decode('unicode_escape').encode('latin1').decode('utf-8').replace('\\/', '/'))
    for v in d.values():
        print(' / '.join(v['option_value_orginal']), v['option_price'], v['is_selling'])
    ```
    첫 번째 `option_stock_data`만 본상품이다(뒤에 나오는 것은 추가구성 상품).
  - 상세 이미지: `<img src>` 중 상품 상세용 URL(KOYU는 `koyuhaus.speedgabia.com/...`)을 모두 받는다.
    공백은 `%20`으로 바꾼다.
- **이미지 첨부면** 그 이미지를 그대로 읽는다.
- 상세 이미지는 세로로 매우 길다. PIL로 높이 1,900px 단위로 잘라 Read로 **처음부터 끝까지** 본다.
  원단·충전재·인증·가공·세탁 테스트 문구는 앞쪽 이미지에, 상품 정보 표(소재·제조국·사이즈)와
  세탁 안내는 마지막 이미지 하단에 있는 경우가 많다.

## 2. 출력 양식 (그대로 따른다)

```
[제품 스펙]

* 원단 : {원단명(영문 상표)} {원사 굵기} {혼용률} ({기능})
   * {원단 특징 설명 1문장}
   * {원단 장점 1문장}
* 충전재 : {충전재명(영문)} {특징어}
   * {설명 1문장}
   * {설명 1문장}
* 인증 : {시험기관} {시험 내용}
   * {주요 수치 — 예: 진드기 투과율 0%, KC 3대 TEST 완료}
* 가공 : {가공명} ({설명})
* 관리 : {세탁기·건조기 사용 가능 여부} ({세탁 TEST 여부})
   * {세탁견뢰도·치수변화·필링 등 수치}
   * {세탁 방법 1~2문장: 수온·세제·세탁망·코스·건조}
* 제작 : {국내/해외} 생산 (제조국 {국가}, 판매·제조원 {회사})
* 정상가 : {기본 구성} {소비자가}원 (소비자가)
   * 판매가 : {판매가}원 (약 {할인율}% 할인)
   * 쿠폰 적용가 : {쿠폰가}원 ({쿠폰액}원 쿠폰, 약 {할인율}% 할인)
* 사이즈별 가격 (판매가 기준)
   * {구성 1} : S/SS {가격}원 / Q {가격}원 / K {가격}원
   * {구성 2} : S/SS {가격}원 / Q {가격}원 / K {가격}원
* 사이즈 : S/SS {가로×세로}cm / Q {…}cm / K {…}cm (±{오차}cm), {부속품} {…}cm
* 사용 계절 : {계절}
```

## 3. 규칙
- 숫자(가격·사이즈·혼용률·시험 수치)는 페이지 표기 그대로 옮긴다. 금액은 천 단위 쉼표 + `원`.
- 할인율만 계산한다: `1 - 판매가(또는 쿠폰가) / 소비자가`를 정수로 반올림해 "약 N%"로 쓴다.
- 사이즈 기호는 `×`, 단위 `cm`. 상세에 `K/LK`처럼 표기되어 있어도 옵션이 `K`면 옵션 표기를 따르고 아래에 남긴다.
- 설명 문장은 상세페이지 문구를 근거로 짧게(한 문장) 다듬는다. 페이지에 없는 효능·수치를 만들지 않는다.
- 페이지에 해당 정보가 없는 항목(예: 충전재가 없는 커버류, 인증 없음)은 줄을 지우지 말고
  `상세페이지에 없음`으로 적는다.
- 양식 아래에 `확인 필요:` 목록을 붙여 페이지 안 표기 불일치(상품명, 사이즈 표기, 판매중지 옵션 등)를 적는다.
  없으면 생략한다.
- 결과는 채팅에 출력한다. 여러 상품이면 상품별로 반복한다.
